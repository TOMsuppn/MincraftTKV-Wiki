# Eco Help（经济帮助）

### `/eco help`

#### 命令格式：

```
/eco help
```

#### 执行对象：

* 仅**玩家**

#### 权限：

* **minecrafttkv.eco.use**

#### 用途：

* 打开经济系统帮助面板
* 查看当前可用的经济命令

#### 功能说明：

* 会显示当前货币名称和货币符号
* 会展示 `/eco balance`
* 会展示 `/eco pay`
* 会展示 `/eco top`
* 当玩家直接输入 `/eco` 时，实际也会进入帮助面板

#### 常见示例：

```
/eco help
/eco
```

#### 注意事项：

* **仅玩家**可以执行
* 如果经济系统已关闭，则玩家无法正常使用经济命令
* 帮助面板中部分命令是否能真正使用，仍取决于玩家自身权限
