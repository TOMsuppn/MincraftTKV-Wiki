# Market Help（市场帮助）

### `/market help`

#### 命令格式：

```
/market help
```

#### 执行对象：

* 仅**玩家**

#### 权限：

* **minecrafttkv.market.use**

#### 用途：

* 打开市场帮助面板
* 查看跳蚤市场相关功能入口

#### 功能说明：

* 会展示市场主页、浏览、上架、我的挂单、任务和商人入口
* 会显示市场当前开关状态
* 会显示任务系统状态、商人系统状态和当前在售数量

#### 常见示例：

```
/market help
```

#### 注意事项：

* **仅玩家**可以执行
* 即使能打开帮助，后续具体功能是否可用仍取决于系统是否启用
* 当前版本中，市场相关操作仍受藏身处限制
