# Market（市场主页）

### `/market`

#### 命令格式：

```
/market
/market open
/market gui
```

#### 执行对象：

* 仅**玩家**

#### 权限：

* **minecrafttkv.market.use**

#### 用途：

* 打开跳蚤市场总入口
* 打开市场主页 GUI

#### 功能说明：

* 输入 `/market` 时会直接打开市场主页
* `/market open` 和 `/market gui` 也会打开同一个市场主页
* 玩家可从主页继续进入浏览、上架、我的挂单、任务和商人系统

#### 常见示例：

```
/market
/market open
/market gui
```

#### 注意事项：

* **仅玩家**可以执行
* 必须拥有 `minecrafttkv.market.use` 权限
* 当前版本中，跳蚤市场只能在**藏身处内**操作
