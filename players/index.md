# 玩家命令目录

### `MinecraftTKV 玩家命令`

#### 命令格式：

```
docs/player-commands/
```

#### 执行对象：

* 文档使用者

#### 权限：

* **无需权限**

#### 用途：

* 汇总当前所有玩家可用命令说明
* 方便单独查阅每一条玩家命令

#### 功能说明：

* 当前目录已生成以下玩家命令文档：
* `mhelp.md`
* `play.md`
* `eco-help.md`
* `eco-balance.md`
* `eco-pay.md`
* `eco-top.md`
* `mstats.md`
* `mprogress.md`
* `mpass.md`
* `market-home.md`
* `market-help.md`
* `market-browse.md`
* `market-sell.md`
* `market-my.md`
* `market-task.md`
* `market-trader.md`

#### 常见示例：

```
打开 docs/player-commands/ 下的单独文件查看对应命令说明
```

#### 注意事项：

* 当前仅制作了**玩家可用命令**
* 管理命令和系统命令暂未写入这个目录
* 所有文件均按指定模板格式编写
