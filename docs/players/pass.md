# 🎫 Mpass（通行证）

### `/mpass [页码]`

#### 命令格式：

```
/mpass
/mpass <页码>
```

#### 执行对象：

* 仅**玩家**

#### 权限：

* **minecrafttkv.pass.use**

#### 用途：

* 打开战令通行证 GUI
* 查看战令等级、普通奖励、典藏奖励和解锁状态

#### 功能说明：

* 不填写页码时，系统会自动定位到当前最相关页
* 填写页码时，会跳转到指定页面
* **Tab 补全**会根据当前总页数给出数字建议
* GUI 中可查看战令代币数量、可解锁等级、普通奖励和典藏奖励

#### 常见示例：

```
/mpass
/mpass 1
/mpass 2
```

#### 注意事项：

* **仅玩家**可以执行
* 如果战令系统未启用，命令无法使用
* 如果页码不是数字，系统会提示格式错误
* 典藏奖励是否可领取，还取决于玩家是否拥有典藏资格
