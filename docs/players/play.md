# 🎮 Play（匹配）

### `/play [mapId]`

#### 命令格式：

```
/play
/play <mapId>
```

#### 执行对象：

* 仅**玩家**

#### 权限：

* **无需权限**

#### 用途：

* 进入地图匹配流程
* 可指定某一张地图进行战局搜索

#### 功能说明：

* 不填写 `mapId` 时，插件会按当前匹配逻辑处理默认地图搜索
* 填写 `mapId` 时，会将该值传入战局搜索流程
* **Tab 补全**会从当前已加载地图中给出地图 ID 建议
* 匹配逻辑会交给 RaidSearch 系统继续处理

#### 常见示例：

```
/play
/play Factory
/play Woods
```

#### 注意事项：

* **仅玩家**可以执行
* 地图 ID 取决于当前服务器加载到的地图模板
* 如果填写了不存在的地图，后续是否成功进入战局取决于匹配系统的处理结果
