# 😎 关于MinecraftTarkov

**MinecraftTKV**是一款致力于为我的世界开发**搜打撤玩法**的服务器插件。

它基于**SpigotAPI**开发兼容<kbd>**Paper、Spigot、Bukkit、Purpur、Mohist、Youer、ArcLight**</kbd> 等众多主流服务器核心。

目前支持**1.21.X与1.20.X版本，模组混合端在支持范围内**。
