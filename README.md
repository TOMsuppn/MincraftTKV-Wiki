# 😎 关于MinecraftTarkov

**MinecraftTKV**是一款致力于为我的世界开发**搜打撤玩法**的服务器插件。

它基于**SpigotAPI**开发兼容<kbd>**Paper，Spigot，Bukkit，Purpur，Mohist，Youer**</kbd> 等众多主流服务器核心。

目前仅支持**1.21.X**版本，未来会推出对**1.20.X**的支持。
