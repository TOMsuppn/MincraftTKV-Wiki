# 🧭 Mhelp (Player Command Help)

### `/mhelp`

#### Command format:

```
/mhelp
```

#### Executor:

* **Players only**

#### Permission:

* **minecrafttkv.help.use**

#### Purpose:

* Opens the player help panel
* View shortcuts to commonly used player commands on the current server
* View basic runtime status information

#### Features:

* Displays the plugin name, version, and author information
* Shows shortcut entries for commonly used commands currently available to the player
* Displays online player count, TPS, MSPT, AI status, and plugin status
* No additional parameters are required; entering the command opens the help panel directly

#### Common example:

```
/mhelp
```

#### Notes:

* **Players only** can run this command
* Players without the `minecrafttkv.help.use` permission cannot use it
* This is the main help entry point recommended for players to check first
